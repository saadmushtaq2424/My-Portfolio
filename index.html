04 — Process

How I take a project
from brief to deploy.

01

Understand the Brief

Go through the client's brand deck, reference site, or Figma file line by line before writing a single tag.

02

Structure the Build

Plan pages, includes, and a config layer (config.php, apiFetch()) so the codebase stays consistent.

03

Design-to-Code

Convert Figma exports into pixel-accurate, responsive HTML/CSS with a proper design token system.

04

Wire the Frontend

Build out interactive UI — modals, tables, calendars, dashboards — in vanilla JS or React.

05

Integrate APIs

Connect REST endpoints with Bearer/JWT auth, handle loading and error states, and sync MySQL-backed data.

06

Test Across Devices

Check cross-browser and mobile behaviour, fix edge cases, and confirm data accuracy end to end.

07

Deploy

Ship to production — handling server-specific quirks like Linux case-sensitivity — and hand over clean files.

08

Support & Iterate

Stay available for fixes, new modules, and feature requests as the product grows.
